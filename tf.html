Describe the AWS pieces you want. Get a complete, organized Terraform project you can download and run.

This page is a generator. You tick a few boxes, type a few names, and it writes the files for you: reusable modules (the building blocks) and a separate infrastructure folder (where you actually use those blocks). Nothing is sent anywhere — everything happens inside your browser.

What it builds

EC2 servers running Docker images (Keycloak, NiFi, Kafka) behind a load balancer with auto scaling, plus S3 buckets, a Lambda file mover, and a Step Functions workflow.

How you steer it

Tick services, or paste a plain list of AWS services and let the page read it. Export your choices as a small schema file and import it again later.

What you get

A ZIP (or a single setup script) containing modules/, infrastructure/, examples/, a README, and a diagram of how it all connects.

First time here? Read this paragraph.

Imagine you want to build a LEGO castle. You could snap bricks together by hand every time (that is clicking around the AWS website), or you could write down the instructions once and hand them to a robot (that is Terraform). The instructions are plain text files ending in .tf. The robot reads them, calls AWS, and builds exactly what the instructions say. If you change the instructions and run the robot again, it changes only the parts that need changing. If you say "undo", it takes the castle apart.

Money and safety warning, in plain words

Everything on this page creates real AWS resources that cost real money once you run it. Load balancers, NAT gateways, and EC2 servers charge by the hour whether you use them or not. The generated code is a learning and starting-point project: it uses demo passwords, single-node Kafka, and Keycloak in dev mode. Do not put real customer data in it until a security-minded adult reviews it. When you are done experimenting, run terraform destroy.
