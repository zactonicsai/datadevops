06 — FIREWALLS

  
Security group vs NACL

  

    The difference that causes the most confusion: security groups remember the conversation,
    NACLs don't. Send a request through both and see where the reply gets stuck.
  


  

    

      
Stateful vs stateless

      

        Allow inbound 443 on both. Then send a request and watch the return trip.
      

      

        

          NACL outbound rule for ephemeral ports 1024–65535
          

        

      

      
      

    


    

      
NACL rule order

      

        Rules run lowest number first and the first match wins. Drag the deny rule's
        number below 100 to make it actually work.
