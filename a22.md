Worth separating what they're actually asking for, because "gateway" here means something specific and it's a broader grant than it sounds.

**What AgentCore Gateway is**

It turns Lambda functions, OpenAPI/REST APIs, and Smithy models into MCP tools an agent can call. Creating one requires a name, protocol type, and an IAM role that grants the gateway permission to access AWS services and resources. So it's not a read-only endpoint — it's an integration point that can reach into other services on the agent's behalf.

**Two distinct roles are involved** A Gateway Execution Role that the service assumes at runtime to invoke targets, and a Resource Management Role that administrators use to create and manage the gateway. Your data scientist is asking for the second one; the first is what actually determines blast radius.

**Minimum grant for the management side** AWS's example policy scopes to `bedrock-agentcore:*Gateway*`, `*WorkloadIdentity`, `*CredentialProvider`, `*Token*`, and `*Access*` on gateway ARNs, plus `s3:GetObject`/`PutObject` if they'll host OpenAPI schemas in S3 and KMS encrypt/decrypt permissions.

**Three things I'd pin down before approving**

1. **Does the request include `iam:CreateRole`/`PassRole`?** Console and CLI creation will auto-create a service role and auto-attach target permissions each time a target is added. That's convenient and also means role scope grows silently. Better: you pre-create the execution role, they pass it.
2. **Inbound auth.** Gateway uses JWT token-based authentication rather than standard IAM for who can invoke it — so ask which IdP/Cognito pool fronts it, or you've got an MCP endpoint outside your usual IAM controls.
3. **Which targets.** Lambda-only is low risk. OpenAPI targets with an API key or OAuth credential provider means secrets and outbound calls to third parties.

**Reasonable middle ground:** grant management permissions in a sandbox account, pre-provision the execution role yourself scoped to a specific Lambda prefix, and require them to come back for anything touching production data sources.
